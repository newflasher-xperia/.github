# Newflasher - Write a Sony Firmware Set You Already Unpacked

## Product Snapshot

Sony's firmware arrives as a bundle of SIN and related files for one device. Newflasher sends that set over USB while the phone is in the mode the guide describes. You put the executable next to the unpacked files, or you point it at that folder, and you read the prompts. There is no catalog inside the program.

Back up what you can first. A full flash is not a photo export. If the phone still boots, copy data before you enter flash mode.

## The Folder

| Piece | What you check |
|---|---|
| Model | The Xperia you are holding |
| Unpacked files | Complete, from one download |
| Newflasher build | One the current Sony files still work with |
| USB | A data cable, phone charged |
| Prompts | Answered for this set, not from a different model's notes |

Do not drop a second model's files into the folder to "fill gaps." A missing file means the download failed. Fetch it again.

## Steps

1. Unpack one firmware into an empty directory.
2. Confirm the model name in that package.
3. Connect the phone in the flash mode Newflasher expects.
4. Run the tool from that directory and read each prompt.
5. Wait until it finishes and the phone reboots.
6. If it does not boot, repeat this same folder before you try another region.

## Fits

Xperia owners flashing a stock set they downloaded for their model. A poor fit for other brands. A poor fit for account removal. A poor fit if the folder is a mix of two downloads.

## Fixes

The tool does not see the phone. Mode, driver, or cable.
A prompt names a file you do not have. The unpack is incomplete.
The phone rejects the set. The bootloader is newer, or the model is wrong.
You flashed and the data is gone. The mode you confirmed did that. Restore from the copy you made.
Newflasher is older than the firmware. Use a build current for those files.

## One Unpacked Set in an Empty Folder

Newflasher writes the Sony files sitting next to it. Mix two downloads in that folder and a prompt will ask for a file from the wrong set, or worse, it will flash a blend. Unpack one firmware into an empty directory. Read the model. Connect the phone only when that folder is the one you mean. If a prompt names a missing file, the download did not finish. Fetch it again. Do not drop a similarly named file from another Xperia into the gap.

Back up photos before flash mode. A full write is not an export. If the phone rejects the set, the bootloader may be newer than the files, or the model is wrong. Repeat this folder once. A different region is a different decision, made before you enter flash mode, not after a failure you have not read.

- Empty folder per model and build
- Prompts read, not skipped from another guide
- Incomplete unpacks not patched with stray files
- Data copied first if the phone still boots
- Same folder retried before a region change
- Cable left alone until the tool finishes
- Newer Newflasher used when the firmware is newer than the tool

| Prompt | Meaning |
|---|---|
| Missing file | Unpack again |
| Phone not seen | Mode, driver, or cable |
| Set rejected | Model or anti-rollback |
| Data gone | The mode you confirmed |

The folder name should include the model. Newflasher will not remind you next week.
